# Brand marks

The marks on the Shop by brand tiles. Each was taken from Wikimedia Commons,
where the licence is published per file, and only files in the public domain
were used — a wordmark set in plain type is generally not copyrightable.
They are shown to name the houses this shop stocks, which is what a brand
index is for.

Each was rendered from the original, had any opaque background flooded away,
and was trimmed to its own ink so the tile controls the size.

Brands with no freely licensed mark show their name set as type instead, which
the tile does automatically when a brand has no image: NIKE, New Balance,
GOLDEN GOOSE, BALENCIAGA, Longchamp.

To replace any of these with the shop own artwork, set the brand image in
the app theme editor; the tile prefers whatever is set there.
